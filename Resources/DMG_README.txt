PhoneBridge 安装说明
===================

系统要求：
- Apple Silicon Mac（M1 / M2 / M3 / M4 等）
- macOS 13 或更高版本

安装：
1. 将 PhoneBridge 拖到“应用程序”文件夹。
2. 首次启动时，在“应用程序”中右键 PhoneBridge，选择“打开”。
3. 按系统提示允许“本地网络”访问；普通 iPhone AirPlay 投屏需要 Mac 与 iPhone 位于同一局域网。

如果 macOS 仍提示无法验证开发者：
1. 打开“系统设置 → 隐私与安全性”。
2. 在安全提示下点击“仍要打开”。

本安装包已经内置 UxPlay、GStreamer、scrcpy 和 ADB，不需要安装 Homebrew。

iPhone 文件传输：数据线连接用于读取照片/视频。把 Mac 文件拖到 iPhone 面板，或点击“传输到手机”，会生成一次性下载页；iPhone 下载后可在“存储到文件”中选择位置。Charles CA 下载后仍需手动安装并开启完全信任。
Mac 文件区：文件右键可拷贝；空白区域右键可新建文件夹、新建文件或粘贴 Finder 项目。顶部路径可点击任意层级跳转；手机文件拖到左侧任意位置都会保存到当前 Mac 目录。
文本传输：在任一手机面板点击“文本”。Android USB/ADB 会自动打开接收页；iPhone 扫描二维码。手机页面可复制文本、分享到备忘录或直接打开网站链接。
iPhone 投屏：打开“无线连接”，最上方可直接设置名称、选择内嵌/独立窗口并启动接收器，不需要先插数据线。普通局域网无法发现时，可启用附近设备模式并使用界面 PIN。

截屏与录屏：投屏画面出现后，使用侧栏底部的“截屏 / 开始录屏”按钮；停止录制后可修改录像名称并选择 Mac 保存位置，下次会自动打开上次文件夹。iPhone 两种显示方式都直接保存投屏帧，不需要屏幕录制权限；Android 投屏的窗口采集首次需要授予“屏幕与系统录音”权限。
Android 文件传输/投屏：打开开发者选项和 USB 调试，并在手机上允许调试授权。点击“照片 / 视频”会自动扫描媒体并加载缩略图；投屏固定使用 scrcpy 独立窗口，支持键鼠控制、剪贴板和拖放。点击“传输到手机”可选择具体 Android 目标目录，Mac 文件也可直接拖到手机面板。
无线传输：点击主界面底部“无线传输”，手机扫描二维码后可向 Mac 上传照片/视频，也可下载 Mac 共享的文件。
手机传到 Mac 的文件会以传输完成时间作为 Finder 修改日期，便于按日期查找；文件内部拍摄时间不变。

说明：当前安装包使用临时签名，未经过 Apple 公证。若要让所有接收方像 App Store 应用一样双击即开，需要 Apple Developer ID 证书并提交 Apple 公证。
